# 忆像成章 Logo 资产

## 文件

- `yixiangchengzhang-logo.svg`
  - 横版主 logo，适合项目封面、PPT 首页、海报、答辩牌、官网头图
- `yixiangchengzhang-mark.svg`
  - 图形版 logo，适合 App 图标草案、角标、社媒头像、封面角落标识

## 设计含义

- 主图形由“胶片般的记忆轨迹 + 书页/章节”组合而成
- 上扬的弧线代表影像、时间与故事生成过程
- 下方展开的书页代表“成章”，强调人生记忆被整理成完整叙事
- 右上角的星芒代表 AI 创作、灵感点亮与高光瞬间
- 色彩采用琥珀橙、酒红棕、墨绿黑，兼顾人文温度与科技感

## 建议使用

- PPT 背景浅色时优先使用横版主 logo
- 深色背景上可直接使用当前版本，也可后续再做反白版
- 如果要上架到 Android 工程图标体系，建议下一步再单独出一版更简化的 launcher icon
